# 首个公开钣金机箱样例：Laser4DIY

整理日期：2026-10-26。来源：FabLab München e.V. 的公开硬件机箱项目。原始设计采用 CERN-OHL-P v2；原始声明与许可随包保存。所有下载的 CAD 字节保持不变，预览图和验证记录由本次整理生成，不是 AI 生成几何。

- 仓库：https://github.com/Laser4DIY/Laser4DIY_Enclosure
- 固定版本：`67dce7facd462c5cb7868c0735f005edb44ef3dd`（2023-02-14）
- 原作者装配说明：https://wiki.fablab-muenchen.de/spaces/L4DIY/pages/204768513/Laser4DIY%2BEnclosure%2BAssembly
- 首轮输入：`input/Enclosure-v3-v9.step`，原名 `CAD/Enclosure v3 v9.step`，2,668,414 字节。

## 为什么选它

它是包含箱体、盖板、隔板、折弯连接件、角件和其他组件的真实公开三维装配。作者提供配套下料 DXF、折弯参考 DXF 和装配说明。官方说明涉及 1 mm 不锈钢板、折弯、铆钉连接及盖板点焊，比单个矩形/支架更接近好运来的机箱工作。材质具体牌号、各组件厚度仍需逐件核对，不能把整组装配全部当成 1 mm SS304。

## 文件分组

| 目录/文件 | 用途 |
|---|---|
| `input/Enclosure-v3-v9.step` | 唯一首轮待解析输入，包含原有装配关系和几何 |
| `reference/lasercut/1mm_steel/laserenclosure2_v60/` | 原作者的 16 份下料 DXF；其中含组合排布与单独垫片的不同表示，不能按文件数累计零件需求 |
| 上述目录中的 `bend_diagrams/` | 原作者的 10 份折弯参考 DXF；并非每件都提供完整角度、公差或工艺要求 |
| `reference/README.upstream.md` | 原作者原始说明及版权声明 |
| `LICENSE-CERN-OHL-P-v2.txt` | 原始许可全文 |
| `preview/enclosure.png` | 由输入 STEP 的原始几何生成的预览；右侧仅隐藏盖板组以便查看 |
| `source-manifest.json` | 固定下载地址、Git blob SHA-1、SHA-256、字节数和输入/参考角色 |
| `verification/geometry-preview.json` | 现有 OCCT 导入器的几何与层级读取结果 |
| `verification/dxf-parse.json` | 现有 DXF 解析器对 26 份文件的语法、实体类型及单位检查 |

首轮读图只提供 `input/`。`reference/` 用于后续独立对照，不直接提供给模型冒充识别结果。

## 版本为什么固定在旧快照

最新仓库保留了 2023-02 的总装 STEP，却新增了 2023-06 的 `laserenclosure4_v7/`、文件名 v8 的 DXF。混用会造成版本差异。本包采用同一旧提交下的 `laserenclosure2_v60/`，名称与总装中的 MainSheet、CompartmentLeft/RightSheet、Labyrinth 等对应。

固定同一提交和名称对应只能减少版本错配，尚未证明每一份下料图都与成形几何、折弯补偿完全一致；这些仍是后续验证项。

## 本次已经验证

- 29 份下载原件全部与固定版本的 Git blob 哈希匹配：1 STEP、26 DXF、原始 README 和许可。
- STEP 能被现有 OCCT 组件实际读取并生成 38 个显示网格、65,298 个三角形，保留装配分组。网格数量不是制造零件数量；重复实例、复合实体和非钣金件要分别处理。
- 26 份 DXF 均能被现有解析器读取，共 2,408 个顶层实体。
- 部分 DXF 有 `$INSUNITS=4`（毫米），部分未声明单位；未声明不能静默当毫米。
- 主下料图包含大量 SPLINE，折弯参考图包含 LWPOLYLINE、CIRCLE 和 LINE，适合检验曲线处理与跨格式归属。

以上验证没有调用 AI、没有执行第三方项目代码、没有安装 CAD 软件，也没有修改线上工作台。它证明文件可用及预览能力，尚不证明自动拆件、板厚识别、真实展开或核价准确。

## 建议首先做的验证

1. 从总装保留原装配层级，区分箱体、盖板、隔板、角件、重复件及其他组件。
2. 让工程师能选择一个原有部件并查看几何；先聚焦 MainEnclosure、盖板和角件，其他组件可以排除。
3. 核对原件中的孔、槽、板壁与折弯候选；逐件记录单位与来源，不按网格数、文件数猜 BOM。
4. 在独立阶段打开原作者下料和折弯参考图，检查部件对应、内孔、曲线及尺寸；需要补偿参数时保持待确认。
5. 将已确认的特征关联切割、折弯、铆接或点焊工序卡。铆钉连接与压铆螺母不是同一种工序。

这个样例没有完整的工厂工时、报价、材料价和全部表面处理要求，也不覆盖好运来全部 24 项收费工序。它可以先启动真实文件处理的开发，后续再用客户原始 CAD 做适配，无需客户先整理完整资料包。
